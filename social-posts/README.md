# STRAYD Social Content Library

Generated by the Strayd Content Director GitHub Action.

## Folders

- `weekly/`: weekly Markdown calendars.
- `daily/`: individual TXT files containing five content types.
- `approved/`: reserved for explicitly approved content.
- `published/`: reserved for confirmed publishing records.

## Important

Generated content is draft material. It is not automatically approved or published. Unique run IDs prevent later runs from overwriting earlier generated files.
